# 小猫 · Low Poly

A deliberately rough low poly, animated three.js version of a mint-green kitten, built from a hand-drawn three-view sketch.

- Tap the kitten to make it react. Drag to turn the view; pinch or scroll to zoom.
- 12 actions plus an auto performance; 5 scenes (room, street, beach, snowy night, island).
- **⛶ 全屏录屏** (fullscreen recording) leaves only the picture, edge to edge, for screen recording. Hold anywhere on it for 1 second (or press Esc) to leave.
- On iPad: Safari → Share → Add to Home Screen opens it full-screen like an app.

A single static `index.html`; three.js loads from jsDelivr.
